# CSL-JSON schema

`csl-data.json` is the JSON schema of CSL-JSON, the data model of the Citation Style Language, copied unchanged from the repository [citation-style-language/schema](https://github.com/citation-style-language/schema), file `schemas/input/csl-data.json` at commit `40b3ce0bbbda517ad14b98c93a2c65ab4cde56a9`. `LICENSE.txt` is that repository's license (MIT).

The catalog's tests validate every shipped publication's CSL-JSON item against it.
